## Manage Workflow 
 
| Shortcut | Action | 
|---|---| 
| Ctrl+C | Copy object | 
| Ctrl+X | Cut object | 
| Ctrl+V | Paste object | 
 
| Ctrl+Z | Undo last action | 
| Ctrl+Y | Redo last action | 
| Ctrl+[ | Cancel current command (or Ctrl+\) | 
| ESC | Cancel current command |  
| Ctrl+D | Toggle coordinate display | 
| Ctrl+G | Toggle Grid | 
| Ctrl+F | Toggle Snap |
